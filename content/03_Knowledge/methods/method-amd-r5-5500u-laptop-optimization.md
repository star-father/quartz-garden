# AMD R5-5500U 轻薄本升级优化全方案

> 适配设备：R5-5500U 平台轻薄本 + Win10 专业版
> 适用场景：Hyper-V 虚拟机运行、Obsidian 知识库管理、Git 代码同步、轻量开发工作
> 来源：用户手动粘贴贡献（2026-08-05），按知识库入库规则编译 frontmatter 后归档。

## 一、设备基础信息

| 项目 | 参数详情 |
|------|----------|
| 处理器 | AMD Ryzen 5 5500U 2.10GHz（6 核 12 线程，低压移动处理器） |
| 内存 | 16.0 GB（板载 8GB + 插槽 8GB，可用 15.4GB） |
| 系统 | Windows 10 专业版 22H2（内部版本 19045.3803） |
| 接口特征 | 单 Type-C 全功能口（充电 + 数据复用），剩余 USB-A 接口 |
| 硬件上限 | 板载内存焊死，最高可升级至 24GB（板载 8G + 插槽 16G），无法实现 32GB |

### 连接与采购注意事项

1. 扩展坞必须支持 PD 输入直通，仅带 C 口输出的普通扩展坞无法为电脑供电
2. 内存仅兼容 DDR4，不支持 DDR5；无需购买 32GB 单条，硬件限制最高识别 24GB
3. 标准连接顺序：
   1. 笔记本原装 65W 充电器 → 扩展坞 PD-IN 口
   2. 扩展坞 C-C 数据线 → 笔记本 Type-C 口
   3. 移动 SSD → 扩展坞蓝色 USB-A 3.0 接口

## 三、Windows 10 系统优化方案

### 1. 内存与后台优化

- 关闭冗余后台应用：设置 → 隐私和安全性 → 后台应用，仅保留必要输入法进程
- 虚拟内存配置：此电脑右键 → 属性 → 高级系统设置 → 性能设置 → 高级 → 虚拟内存更改
  - 取消「自动管理所有驱动器的分页文件大小」
  - 系统盘（C 盘）自定义大小：初始 4096MB，最大 8192MB
  - 虚拟内存请勿放置在外接 SSD，仅保留于系统盘
- 关闭休眠功能（管理员 CMD 执行）：`powercfg /hibernate off`

### 2. C 盘与存储优化

- 开启存储感知：设置 → 系统 → 存储，自动清理临时文件与更新缓存
- 定期磁盘清理：运行 `cleanmgr`，勾选「Windows 更新清理」释放冗余空间
- 文件存放规则：
  - C 盘仅存放系统与软件
  - Obsidian 知识库、Git 仓库、项目文件存放于内置 D 盘
  - Hyper-V 虚拟机磁盘专属存放于外接 SSD

### 3. 系统服务精简

运行 `services.msc`，可禁用以下非必要服务：

- `SysMain`（固态硬盘无需预读加速）
- `Diagnostic Tracking Service`（系统诊断遥测，不影响系统更新）

## 四、Hyper-V 虚拟机专项优化（CentOS）

兼顾虚拟机性能与宿主系统流畅度：

1. **CPU 分配**：最多分配 4 个虚拟处理器，预留 2 核保障宿主系统运行
2. **内存配置**：启用动态内存
   - 最小内存：2048MB
   - 最大内存：6144MB（16GB 机型）；升级 24GB 后可上调至 8192MB
3. **存储配置**：虚拟硬盘（VHDX）全部存放于外接 SSD，禁止使用 U 盘 / 机械盘
4. **功能优化**：关闭自动快照，避免快照文件占用大量磁盘空间
5. **操作禁忌**：虚拟机运行期间禁止热插拔外接 SSD 与扩展坞，防止虚拟磁盘损坏

## 五、Obsidian + Git 工作流优化

### 1. Obsidian 性能优化

- 禁用闲置第三方插件，仅保留核心同步、编辑插件
- 大体积 Markdown 文件优先使用 VS Code 打开，降低内存占用
- 知识库固定存放于内置固态 D 盘，不放置在外接 SSD，保障 Git 同步稳定性

### 2. Git 内存限制配置

执行以下命令限制 Git 打包内存，避免大仓库同步时内存溢出：

```bash
git config --global pack.windowMemory "100m"
git config --global pack.packSizeLimit "100m"
```

## 六、电源与性能优化

1. 外接电源时切换为「高性能」电源计划；电池模式下避免运行虚拟机，防止 CPU 降频卡顿
2. 关闭快速启动：控制面板 → 电源选项 → 选择电源按钮的功能，取消勾选「启用快速启动」，解决外接 USB 设备识别异常
3. AMD 核显设置为全局均衡模式，闲置场景降低功耗

## 七、验证与避坑清单

- [ ] 扩展坞连接后，笔记本正常充电，外接 SSD 可正常识别读写
- [ ] 内存升级后，系统属性确认总内存为 24GB
- [ ] 新 SSD 完成完整性校验，确认无扩容虚标
- [ ] Hyper-V 虚拟机可正常启动，宿主系统无明显卡顿
- [ ] Obsidian 与 Git 同步无异常，文件无损坏丢失

### ❌ 避坑红线

1. 禁止将 Git 仓库、Obsidian 知识库存放于外接 SSD，频繁 IO 易导致文件冲突损坏
2. 禁止为虚拟机分配超过宿主一半的内存，避免系统整体卡顿
3. 拒绝廉价扩容移动硬盘，虚拟机数据损坏后不可逆
